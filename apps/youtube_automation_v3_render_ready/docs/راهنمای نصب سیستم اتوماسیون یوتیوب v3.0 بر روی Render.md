# راهنمای نصب سیستم اتوماسیون یوتیوب v3.0 بر روی Render

**تاریخ:** 12 اکتبر 2025

**تهیه‌کننده:** Manus AI

این راهنما مراحل گام به گام استقرار سیستم اتوماسیون یوتیوب نسخه 3.0 (YouTube Automation System v3.0) را بر روی پلتفرم Render.com با استفاده از قابلیت استقرار یک‌کلیکه (One-Click Deploy) توضیح می‌دهد. این سیستم شامل سرویس وب FastAPI، پایگاه داده PostgreSQL و سرویس‌های Celery (Worker و Beat) می‌باشد.

## 1. پیش‌نیازها

قبل از شروع فرآیند نصب، اطمینان حاصل کنید که موارد زیر را در اختیار دارید:

*   **حساب کاربری Render:** یک حساب کاربری فعال در [Render.com](https://render.com) (می‌توانید از طرح رایگان برای تست استفاده کنید).
*   **مخزن Git:** یک مخزن Git (مانند GitHub, GitLab, Bitbucket) که پروژه `youtube_automation_v3` در آن قرار گیرد. این مخزن باید عمومی باشد تا Render بتواند به آن دسترسی پیدا کند (یا در صورت استفاده از مخزن خصوصی، Render را به آن متصل کنید).
*   **فایل پروژه:** فایل `youtube_automation_v3_render_ready.zip` که توسط Manus AI تهیه شده است.

## 2. آماده‌سازی پروژه برای استقرار

فایل `youtube_automation_v3_render_ready.zip` حاوی کدهای پروژه و فایل `render.yaml` است که Render برای پیکربندی سرویس‌ها از آن استفاده می‌کند. برای آماده‌سازی پروژه، مراحل زیر را دنبال کنید:

1.  **استخراج فایل‌ها:** فایل `youtube_automation_v3_render_ready.zip` را در یک پوشه محلی استخراج کنید.
2.  **ایجاد مخزن Git:**
    *   یک مخزن Git جدید (مثلاً در GitHub) ایجاد کنید.
    *   محتویات استخراج شده از فایل `zip` را به این مخزن Git اضافه کنید. مطمئن شوید که فایل `render.yaml` در ریشه مخزن قرار دارد.
    *   تغییرات را به مخزن Git خود `push` کنید.

    مثال دستورات Git:
    ```bash
    # فرض می‌کنیم فایل‌ها در پوشه my_youtube_project است
    cd my_youtube_project
    git init
    git add .
    git commit -m "Initial commit for YouTube Automation System v3.0"
    git branch -M main
    git remote add origin <URL_مخزن_شما>
    git push -u origin main
    ```

## 3. استقرار بر روی Render.com

اکنون که پروژه شما در یک مخزن Git قرار دارد، می‌توانید آن را بر روی Render مستقر کنید:

1.  **ورود به Render:** به [Render.com](https://render.com) بروید و وارد حساب کاربری خود شوید.
2.  **ایجاد Blueprint:**
    *   از داشبورد Render، بر روی دکمه **"New"** کلیک کنید.
    *   گزینه **"Blueprint"** را انتخاب کنید.
3.  **اتصال به مخزن Git:**
    *   Render از شما می‌خواهد که مخزن Git خود را متصل کنید. مخزنی را که پروژه `youtube_automation_v3` را در آن قرار داده‌اید، انتخاب کنید.
    *   اگر مخزن خصوصی است، ممکن است نیاز به اعطای دسترسی به Render داشته باشید.
4.  **بررسی و تأیید:**
    *   Render به طور خودکار فایل `render.yaml` را در مخزن شما شناسایی می‌کند.
    *   لیستی از سرویس‌هایی که قرار است مستقر شوند (Web Service, Celery Workers, PostgreSQL, Redis) را مشاهده خواهید کرد.
    *   اطمینان حاصل کنید که تمام سرویس‌ها به درستی شناسایی شده‌اند.
5.  **استقرار (Deploy):**
    *   بر روی دکمه **"Apply"** کلیک کنید تا فرآیند استقرار آغاز شود.
    *   Render شروع به ساخت ایمیج‌ها، راه‌اندازی پایگاه داده و Redis، و سپس استقرار سرویس‌های وب و Celery خواهد کرد.
    *   این فرآیند ممکن است چند دقیقه طول بکشد.

## 4. بررسی پس از استقرار

پس از اتمام موفقیت‌آمیز استقرار، می‌توانید وضعیت سرویس‌های خود را بررسی کنید:

1.  **وضعیت سرویس‌ها:** در داشبورد Render، به صفحه پروژه خود بروید. در آنجا می‌توانید وضعیت هر یک از سرویس‌ها (Web Service, Celery Workers, PostgreSQL, Redis) را مشاهده کنید. همه سرویس‌ها باید در وضعیت `live` یا `running` باشند.
2.  **لاگ‌ها:** برای هر سرویس، می‌توانید لاگ‌ها را مشاهده کنید تا از صحت عملکرد آن مطمئن شوید. به خصوص لاگ‌های Web Service را برای خطاهای احتمالی بررسی کنید.
3.  **دسترسی به Web Service:** Render یک URL عمومی برای Web Service شما فراهم می‌کند. می‌توانید با مراجعه به این URL (معمولاً `https://<your-service-name>.onrender.com/`) از طریق مرورگر، از صحت عملکرد API اطمینان حاصل کنید. می‌توانید به `/health` یا `/` برای بررسی اولیه مراجعه کنید.

## 5. پیکربندی متغیرهای محیطی

فایل `render.yaml` متغیرهای محیطی اصلی مانند `DATABASE_URL` و `REDIS_URL` را به طور خودکار از سرویس‌های Render دریافت می‌کند. با این حال، ممکن است نیاز به تنظیم متغیرهای محیطی اضافی (مانند `LLM_API_KEY` یا `JWT_SECRET_KEY`) در داشبورد Render داشته باشید:

1.  در داشبورد Render، به صفحه تنظیمات (Settings) هر سرویس (Web Service, Celery Worker, Celery Beat) بروید.
2.  در بخش "Environment Variables"، می‌توانید متغیرهای مورد نیاز خود را اضافه کنید. این متغیرها باید با آنچه در فایل `.env.example` پروژه تعریف شده‌اند، مطابقت داشته باشند.

## 6. توسعه و تست

این استقرار بر روی Render برای توسعه و تست بسیار مناسب است. هر زمان که تغییراتی در کد خود در مخزن Git ایجاد و `push` کنید، Render می‌تواند به طور خودکار سرویس‌های شما را مجدداً استقرار (redeploy) کند (در صورتی که این قابلیت را فعال کرده باشید). این امکان، فرآیند تست و توسعه را بسیار کارآمدتر می‌کند.

با این راهنما، شما باید بتوانید به راحتی سیستم اتوماسیون یوتیوب v3.0 را بر روی Render مستقر کرده و از آن برای تست و توسعه استفاده کنید.
